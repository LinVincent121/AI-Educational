# AI教务系统：模块级需求蓝图

> ⚠️ 历史蓝图：仅作产品背景和信息架构参考，不作为开发规则来源。与 `00-product-principles.md`、`shared/` 公共规范及各模块最终 PRD 冲突时，以后者为准。

> 状态：待评审
>
> 本文只定义模块、数据、流程、权限、状态、审核和计算规则；页面字段级和页面级详细功能在本稿确认后继续展开。

## 1. 产品总体定义

系统定位为：

> 以课程为核心工作空间，以课程资料和知识库为基础，以 AI 对话和教学业务模块为主要工作方式的课程教学 AI 工作台。

核心角色：

- 教师：创建、编辑和使用教学内容。
- 教学秘书：审核、管理和维护正式教学材料。
- 系统管理员：维护账号、角色、权限和系统配置。
- 系主任、院长：预留查看权限，暂不开放具体业务操作。

核心业务主线：

```text
用户与权限
  → 课程与课程版本
  → 课程资料库 / 知识库
  → 教学大纲
  → 教学日历
  → 章节备课
  → 课件、作业、试卷
  → 成绩数据
  → 学情与课程能力分析
```

教学大纲是正式教学内容的上游基础；教学日历、备课、课件、作业、试卷和成绩分析都应与大纲、章节、知识点和课程能力指标建立关联。

## 2. 信息架构

### 2.1 顶部全局导航

- 首页
- 我的课程
- 资料库
- 消息提醒
- 系统设置

首页是系统级总览，展示我的课程、最近访问、待处理事项、最近生成内容和常用操作。

我的课程用于查看有权限访问的课程、按学期筛选、查看课程状态并进入具体课程工作空间。

资料库用于查看跨课程的个人资料库、共享资料库、最近上传和待处理文件。

消息提醒用于展示审核、生成、解析、数据导入和版本变更提醒。

系统设置用于个人信息、账号安全、通知、模板、系统权限和数据设置。

### 2.2 课程内导航

进入课程后使用轻量的横向导航：

- 课程总览
- 教学大纲
- 教学日历
- 章节备课
- 课件制作
- 作业管理
- 试卷管理
- 成绩与学情
- 课程资料库
- 版本与审核

课程顶部持续展示：返回我的课程、课程名称、学期、课程版本和当前用户。

## 3. 完整模块清单

### A. 平台基础

- 用户登录：登录、退出、登录状态和账号安全。
- 用户角色：教师、教学秘书、系统管理员及预留查看角色。
- 权限管理：菜单、数据、课程、文件、审核、导出和共享权限。
- 操作记录：登录、文件、编辑、审核、生成、导入、导出和权限变更记录。
- 消息提醒：审核、生成、解析、数据异常等站内消息。
- 版本管理：创建、查看、对比、恢复、作废和关联内容提醒。

### B. 首页与工作台

- 系统首页：课程概览、待办、最近使用、最近生成和快捷操作。
- 课程总览：课程信息、学期、版本、大纲和日历状态、当前教学周、当前章节、待处理事项和课程 AI 入口。
- 课程 AI 对话：基于课程、章节或指定资料提问，生成结果卡片，展示来源，并将结果转存到业务模块。

### C. 我的课程

- 课程列表：名称、编号、学期、负责人、状态、版本和授权角色。
- 课程工作区：进入课程、绑定材料、查看课程状态、成员和课程资料库。
- 课程基本信息：名称、编号、学分、学时、学期、授课对象、课程性质和负责人。
- 课程版本：新建、复制、编辑、提交审核、启用和停用。

### D. 课程资料库与知识库

- 个人资料库：个人教材、历史教案、备课记录和常用题目。
- 课程共享资料库：共享范围、成员、查看、上传、编辑、删除和撤回共享。
- 文件导入：Word、PDF、PPT、Excel、CSV。
- 文件管理：上传、下载、删除、归档、重命名、分类、标签、章节关联、知识点关联、预览和版本。
- 文件解析：章节、知识点、学时、表格、题目、课程目标和能力指标识别。
- 知识库索引：内容清洗、去重、章节索引、知识点索引、来源索引、版本索引和权限过滤。
- 知识库问答：课程资料问答、章节问答、资料对比、摘要、来源引用和相关资料推荐。

课程资料库是教师可见、可管理的资料资产层；知识库是 AI 对这些资料建立的检索和理解层。个人资料和共享资料在创建时选择归属范围，但“共享”不等同于“所有人可编辑”。

AI 检索优先级：

```text
当前课程正式资料
  → 当前课程教师个人资料
  → 当前课程共享资料
  → 经授权的外部资料
```

### E. 教学大纲

- 创建：教材生成、历史大纲解析、空白大纲、历史复制和模板创建。
- 内容：基本信息、章节、学时、知识点、教学目标、重点难点、能力指标及其映射。
- AI：结构提取、目标提取、章节识别、知识点提取、能力指标提取和映射建议。
- 编辑：章节增删排序、学时、知识点、目标、重点难点和能力指标。
- 检查：完整性、学时、目标支撑、能力覆盖、空数据和重复内容。
- 审核：教师提交、教学秘书审核、退回、再提交、通过、正式版本和审核记录。

### F. 教学日历

- 配置：学期、教学周、周学时、节假日、复习、测验和答疑。
- 生成：根据已审核大纲、章节学时和教学周生成草稿。
- 编辑：调整周次、内容、复习、测验、答疑和每周作业。
- 检查：总学时、章节覆盖、重复章节、超出教学周和周学时超限。
- 确认和导出：教师确认、教学秘书审核、退回、通过，导出 Excel、Word、PDF。

### G. 章节备课

- 章节备课空间：自动带入课程、版本、大纲、章节、知识点、能力指标和课程资料。
- 内容生成：重点难点、分步骤讲解、例题、反例、易错点、互动问题、课堂练习、板书和总结。
- 内容管理：编辑、保存、复制、重生成、删除、保存为备课记录、转为课件或教案、关联来源。

### H. 课件制作

- 内容生成：PPT 提纲、页面标题、页面要点、讲义、图表、互动页、例题页和总结页。
- 编辑：页面排序、编辑、单页重生成、删除、复制、来源查看和旧课件更新提示。
- 版本与导出：课件版本、PPT、Word 讲义和 PDF 导出。

### I. 作业管理

- 创建：新建、复制历史作业、上传解析、按章节/知识点/能力指标创建。
- 生成：题目、题型、难度、题量、知识点覆盖、能力覆盖、答案、解析和评分标准。
- 关联：课程、版本、作业、章节、知识点、能力指标、题型、难度、来源、答案和评分标准。
- 检查：题目答案一致性、重复、覆盖、难度、格式和完整性。
- 确认和导出：教师编辑审核、AI 辅助检查、确认、版本和 Word/PDF 导出。

### J. 试卷与题库

- 历史题库：导入题库和试卷、结构化、标签化、修正、去重和来源记录。
- 试卷创建：考试类型、范围、题型、题量、难度、章节比例、知识点比例和历史题/新题比例。
- 试卷生成：题库组卷、AI 新题、混合组卷、答案和评分标准。
- 检查：准确性、答案匹配、重复、知识点和能力指标覆盖、题型难度比例、分值合计。
- 安全与导出：权限、答案访问、版本、日志、试卷和答案导出。

试卷暂不自动在线发布，重点是生成、检查、审核和导出。

### K. 成绩管理与学情分析

- 成绩来源：平台作业、平台试卷、Excel、CSV，后续预留外部接口。
- 成绩导入：文件上传、字段映射、学号/姓名/课程/任务识别和预览。
- 成绩校验：姓名、学号、重复、格式、范围、学生、课程和任务匹配。
- 成绩关联：学生、班级、课程、版本、任务、题目、章节、知识点、能力指标、来源和导入批次。
- 综合成绩：作业、试卷、实验等任务按配置权重计算。
- 学情分析：成绩趋势、章节掌握、知识点掌握、能力得分、班级分析、学生分析、薄弱点和教学建议。

考勤数据暂不纳入成绩分析闭环。

## 4. 核心数据对象与关系

核心对象：

```text
用户、角色、课程、学期、课程工作区、课程版本、课程成员、文件、文件版本、资料库、知识库索引、章节、知识点、教学目标、课程能力指标、章节能力映射、大纲、教学日历、备课记录、课件、作业、题目、试卷、学生、班级、成绩、成绩导入批次、学情分析、审核任务、审核意见、操作日志、消息通知
```

关键关系：

```text
用户 ──< 课程成员 >── 课程
课程 ──< 课程版本
课程版本 ──1── 教学大纲
教学大纲 ──< 章节
章节 ──< 知识点
课程版本 ──< 课程能力指标
章节 ──< 章节-知识点关系
章节 ──< 章节-能力指标关系
课程 ──< 资料库 ──< 文件 ──< 文件版本
文件 ──< 知识库索引
课程版本 ──1── 教学日历
章节 ──< 备课记录、课件、作业
作业/试卷 ──< 题目
题目 ──< 章节/知识点/能力指标关系
学生 ──< 成绩
成绩 ──> 作业/试卷、章节、知识点、能力指标
成绩 ──> 学情分析
```

必须结构化保存的关系：文件与课程/版本、章节与知识点、章节与能力指标、题目与章节/知识点/能力指标、成绩与任务/题目/章节/知识点/能力指标、AI 结果与来源文件、内容与版本及审核记录。

## 5. 核心业务数据流

### 5.1 课程资料到教学成果

```text
教师上传资料
  → 文件解析
  → 分类、标签和章节识别
  → 教师确认或修改
  → 进入课程资料库
  → 建立知识库索引
  → AI 对话或业务模块调用
  → 生成教学成果
  → 教师编辑
  → AI 检查
  → 提交审核或导出
```

### 5.2 大纲到后续教学内容

```text
教材/历史大纲
  → 生成大纲草稿
  → 教师编辑
  → 基础检查
  → 教师提交
  → 教学秘书审核
  → 正式大纲版本
  → 生成教学日历、备课、课件、作业和试卷
```

### 5.3 成绩到学情分析

```text
平台成绩或 Excel/CSV
  → 导入预览
  → 字段映射
  → 数据校验
  → 保存成绩
  → 关联课程、任务、章节、知识点和能力指标
  → 计算掌握度、能力得分和综合成绩
  → 生成学情分析
```

## 6. 状态设计

### 6.1 文件

```text
待上传 → 上传中 → 解析中 → 解析成功 → 待确认 → 可使用 → 已归档
```

异常状态：上传失败、解析失败、格式不支持、权限不可用。

### 6.2 教学内容

适用于大纲、日历、课件、作业和试卷：

```text
未创建 → 草稿 → 编辑中 → 检查中 → 待审核 → 审核中
→ 已退回 → 再次提交 → 已通过 → 已确认/已启用 → 已归档
```

个人备课草稿可以不强制进入审核流程。

### 6.3 审核任务

```text
未提交 → 待审核 → 审核中 → 退回修改 → 再次提交 → 审核通过 → 已关闭
```

审核任务保留提交人、审核人、时间、意见、退回原因、处理结果和关联版本。

### 6.4 成绩导入

```text
待导入 → 解析中 → 待校验 → 校验失败/部分通过 → 已确认 → 已作废
```

导入批次必须保留，不能只覆盖原成绩。

### 6.5 共享资料库

```text
个人 → 申请共享 → 已共享 → 暂停共享/撤回共享
```

## 8. 审核机制

### 8.1 必须审核

- 教学大纲
- 正式教学日历
- 正式试卷

### 8.2 不强制审核

- 个人备课草稿
- 个人资料
- AI 对话记录
- 临时分析结果
- 未保存的生成内容

### 8.3 审核前置检查

- 必填项完整
- 学时合计正确
- 章节、知识点和能力关系完整
- 课程目标有支撑
- 题目和答案匹配
- 试卷分值合计正确

AI 只提供检查和建议，不能替代教师或教学秘书做最终确认。

## 9. 核心计算规则

### 9.1 学时

```text
课程总学时 = 所有章节学时之和
教学日历总学时 = 各周教学学时之和
教学日历总学时必须等于教学大纲总学时
```

### 9.2 覆盖率

```text
知识点覆盖率 = 已关联题目的知识点数量 ÷ 当前大纲知识点总数
能力指标覆盖率 = 已关联题目的能力指标数量 ÷ 当前课程能力指标总数
```

### 9.3 综合成绩

```text
综合成绩 = Σ（任务成绩 × 任务权重）
```

所有任务权重合计必须为 100%，且计算规则与课程版本绑定。

### 9.4 章节掌握度

```text
章节掌握度 = 该章节关联题目得分之和 ÷ 该章节关联题目满分之和
```

### 9.5 能力指标得分

```text
能力指标得分 = 关联该能力指标的题目得分之和 ÷ 关联题目满分之和
```

能力维度以当前课程能力矩阵为准，不能固定写死为某一门课程的维度。

## 10. 数据一致性与边界

- 文件、大纲、日历、备课、课件、作业、试卷、成绩和分析都必须绑定课程。
- 大纲、日历、章节、知识点、能力指标及其下游成果必须绑定课程版本。
- 正式版本只能通过复制生成新版本后修改。
- AI 生成结果默认不能直接成为正式内容。
- 外部成绩或题库导入必须保留原文件、批次、字段映射、校验结果和确认记录。
- 课程资料不允许跨课程引用；个人资料用于其他课程时必须复制形成新的课程资料归属。

## 11. 已确认/后续边界

1. 课程和课程版本严格区分；正式成绩只写入当前教学版本，历史版本只读。
2. 共享资料库的管理者是课程负责人、教学秘书，还是两者均可。
3. 课件、作业不需要教学秘书审核。
4. 教学日历必须提交教学秘书审核，通过后才可作为正式日历使用。
5. 课程资料不允许跨课程引用。
6. 个人资料是否可以一键复制到共享资料库。
7. AI 生成内容是自动保存，还是由教师手动保存。
8. 成绩分析是否需要支持班级维度。
9. 学生数据是否只支持教师导入，还是同步预留教务平台接口。
10. 正式大纲审核通过后，教师是否通过新版本继续维护。
