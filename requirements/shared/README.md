# 公共规范

本目录只存放跨多个业务模块复用的规则，不放单个页面的详细需求。

- `data-dictionary.md`：通用数据对象、字段和枚举。
- `permission-status.md`：角色、权限、状态、审核和版本原则。
- `system-architecture.md`：系统调用、异步任务、文件、消息和异常处理。
- `ai-common-rules.md`：大模型使用边界、延迟、并发、引用和结构化输出。
- `analytics-common-rules.md`：埋点公共字段、事件命名和指标定义。
- `platform-foundation.md`：账号、文件、异步任务、通知、审计、搜索、导出和安全等平台基础能力。
