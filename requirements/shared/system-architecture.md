# 公共系统开发规则

## 文件处理

- 大文件采用分片上传和断点续传。
- 原始文件进入对象存储，数据库只保存元数据和存储键。
- 文件解析、OCR、结构提取和知识库构建采用异步任务。
- 每次重试创建新任务，保留原失败记录。

## 接口原则

- 创建和修改接口必须支持幂等键。
- 所有列表接口支持分页、筛选和排序。
- 所有错误返回稳定 `error_code` 和用户可读 `message`。
- 权限失败返回 403，不暴露资源是否存在。
- 状态变化写入操作日志并触发必要的站内通知。

## 异常处理

- 超时：记录任务状态，允许重试。
- 部分成功：保存已完成结果，标记失败范围。
- 依赖服务不可用：展示当前状态和稍后重试入口。
- 数据写入失败：事务回滚，不产生半成品正式数据。
- 页面刷新或离开：任务继续执行，重新进入后恢复状态。
