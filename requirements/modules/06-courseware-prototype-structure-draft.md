# 课件制作原型结构草稿（v0.1）

> 本稿只用于原型绘制前的结构对齐，不涉及代码实现。依据：
> - 北印《2026离散数学PPT》：章节级长课件，常见组织为“问题引入 → 概念/定义 → 表示方法 → 分类/性质 → 定理/证明 → 例题 → 应用 → 总结/练习”。
> - 原交付页面：已有 PPT / 讲义 / 图表三条生成通道、左侧页面缩略图、单页 AI 建议、素材溯源和打开/保存/导出入口。
> - 现有课件 PRD 与章节备课 PRD：课件必须绑定当前课程版本，并优先读取大纲、教学日历、章节备课和课程资料。

## 1. 产品定位

课件制作是“备课成果的可视化编排与交付工作台”，不是单纯的 PPT 生成器。

核心结果：

1. 教师选择一个授课章节/课次，系统带入课程上下文。
2. 系统根据已确认大纲、教学日历、章节备课和课程资料生成“课件骨架 + 页面草稿”。
3. 教师按页审阅、编辑、补充、排序、重生成，并随时查看来源。
4. 同一份章节内容可生成 PPT 页面，页面中的图表、知识结构和互动题作为页面内容的一部分；讲义是 PPT 内容的另一种阅读视图。
5. 课件以版本形式保存，可预览、导出，历史版本不被覆盖。

## 2. 信息架构

```text
课程 / 课程版本
└── 课件制作
    ├── 课件工作台（列表、状态、章节入口）
    ├── 创建课件（来源与生成设置）
    ├── 课件编辑器
    │   ├── PPT 页面
    │   ├── 讲义内容
    │   ├── 图表/知识结构（页面内组件）
    │   └── 来源与版本
    ├── 演示预览
    └── 版本/更新/导出
```

## 3. 页面结构草案

### CW-01 课件工作台

**目标**：让教师知道“哪些章节已有课件、是否过时、从哪里继续”。

- 顶部：课程名、课程版本、学期、当前角色、归档状态。
- 主操作：`新建课件`、`从章节备课生成`。
- 筛选：章节、授课周、课件类型、状态、关键词、是否有资料更新。
- 列表字段：课件标题、章节/课次、页数、来源数、版本、状态、最近更新时间。
- 卡片或行操作：继续编辑、预览、查看来源、查看版本、导出、复制、归档。
- 空状态：优先给“选择章节并生成”，其次给“创建空白课件”。

### CW-02 创建课件（居中弹窗）

弹窗分为三段，背景锁定滚动，底部操作固定：

1. **课件上下文**：当前课程/版本、章节、授课周、授课日期、章节学时；展示“来自备课工作台”的摘要。
2. **来源选择**：章节备课记录（默认优先）、正式大纲、教学日历、课程资料、历史课件；显示文件名、章节、页码范围和版本。
3. **生成设置**：课件类型（PPT；可附带讲义视图）、目标页数、课堂时长、学生水平、教学风格、是否包含例题/互动/总结/讲义备注。

底部操作：`取消`、`创建空白课件`、`开始生成`。

生成前固定提示：AI 输出是教师可编辑草稿；公式、证明、例题和引用需要教师核对；不自动发布、不需要教学秘书审核。

### CW-03 课件编辑器（核心页面）

推荐保留原交付页的三栏骨架，但把“数据来源和章节关系”做得更明确：

```text
┌──────────────┬──────────────────────────┬──────────────┐
│ 页面缩略图   │ 当前页面画布/编辑区       │ 上下文侧栏   │
│ 章节分组     │ 标题、要点、图示、例题   │ 来源/属性/AI │
│ 页码/状态    │ 页面级操作               │ 建议/版本    │
└──────────────┴──────────────────────────┴──────────────┘
```

**顶部工具栏**

- 面包屑：课程 → 章节 → 课件标题。
- 状态：AI 草稿 / 编辑中 / 已保存 / 有资料更新。
- 操作：保存、预览、导出、版本、撤销/恢复。
- 生成进度：课件页面生成显示 queued / processing / partial / success / failed；讲义作为同一课件的派生视图，不单独生成一套内容。

**左侧页面导航**

- 按章节或教学环节分组，而不是只显示连续页码。
- 页面类型标识：标题、概念、定义、例题、证明/推导、图示、互动、总结、练习。
- 页面状态：AI 草稿、教师已改、已确认、来源过时。
- 支持新增、复制、删除、拖拽排序。

**中间页面编辑区**

- 以“页面画布 + 编辑字段”表达，而不是只有一块长文本。
- 标题、副标题、要点、正文、公式/图示占位、例题、互动题、总结、讲义备注。
- 页面布局切换：标题、内容、双栏、例题、对比、图示、互动、总结、空白。
- 选中文字重写、单页重生成；重生成结果先作为候选，不直接覆盖当前页。
- 页面超长、例题缺答案、互动题缺内容时给就地提示。

**右侧上下文侧栏**

- `来源`：文件、章节、页码、片段、来源类型、置信度；无可靠来源显示“需教师核对”。
- `教学关联`：知识点、课程目标、能力指标、授课周。
- `AI 建议`：优化插图、补充案例、添加互动题、建议图表/知识结构、拆分页面；每条支持应用/忽略。
- `版本`：当前页变更记录、旧资料差异、恢复旧版本。

### CW-04 演示预览

- 演示模式：全屏按页播放，保留页码和章节标题。
- 讲义模式：页面内容 + 讲义备注连续阅读。
- 来源模式：每页叠加来源标记，便于课堂前核对。
- 检查清单：空标题、内容超长、公式/图表风险、未确认 AI 内容、例题缺答案。

### CW-05 版本与导出

- 版本时间线：v1.0、v1.1……；记录来源快照、变更说明、操作者、时间。
- “资料有新版本”时提供：查看差异、仅更新当前页、批量生成更新草稿、暂不处理。
- 导出设置：PPTX、DOCX、PDF；页码范围；是否包含讲义备注；来源（无/末尾/逐页）；答案（不显示/显示/单独文件）。

## 4. 跨模块数据链路

```text
课程版本
  ↓
教学大纲（章节、学时、重点难点、目标/能力）
  + 教学日历（周次、日期、课次）
  + 章节备课（教师关注点、教学方式、内容块）
  + 课程资料库（教材/PPT/PDF/讲义，带版本和页码）
  ↓
课件生成上下文
  ↓
课件页面（每页绑定知识点/目标/能力/来源）
  ↓
课件页面内的图表/知识结构、讲义视图、预览、导出、作业素材副本
```

必须坚持：只读当前课程且有权限的资料；复制到作业后形成目标模块的新内容，不建立跨模块实时引用。

## 5. 课件生成的页面语法

北印参考课件提示我们，默认生成器应支持以下“教学叙事段落”，而不是只生成统一内容卡：

1. 问题/案例引入（如七桥问题、城市网络、实际应用）。
2. 本章目标与学习路径。
3. 核心概念与定义。
4. 表示方法、分类和性质。
5. 定理、证明或分步骤推导。
6. 例题与解答。
7. 对比、图示、矩阵或知识结构。
8. 课堂互动/练习。
9. 应用案例。
10. 本章总结与课后练习。

生成设置可以调整各段是否包含、目标页数和密度；页面类型仍落到统一的 `layout_type`，便于编辑和导出。

## 6. 原交付页面的沿用与补齐

**沿用**：PPT/讲义入口、页面缩略图、打开/保存/导出、单页 AI 建议、素材溯源；原先的“图表通道”调整为页面内图表能力。

**补齐**：

- 进入课件前增加课件工作台和创建设置，不再直接落到一份默认课件。
- 明确“章节备课 → 课件”的首选入口，并展示带入的上下文摘要。
- 左侧缩略图增加教学环节分组、页面类型和来源状态。
- 右侧增加知识点/目标/能力关联与来源版本。
- 单页重生成必须保留旧页并等待教师确认。
- 增加旧课件与新资料差异、版本复制和导出设置。
- 修正原页面中“课件标题/章节标题不一致”的问题：课程、章节、课件标题必须分别展示。

## 7. 原型绘制建议（先画这 4 个关键状态）

1. **正常编辑态**：以离散数学“图论基础”作为真实内容，展示 12～20 页缩略图和一页“图的定义/例题”。
2. **从备课生成态**：展示创建弹窗、来源选择、生成进度和逐页回填。
3. **来源/更新态**：右侧展示页码来源，页面标记“资料有新版本”，打开差异并生成候选页。
4. **预览/导出态**：演示预览、讲义预览和导出设置。

## 8. 需要在原型评审时确认的业务问题

- 一次课件是否只允许一个章节，还是允许跨多个章节？
- “从备课生成”是复制备课内容，还是保持可追踪的来源关系？建议：生成时复制快照，保留 source_preparation_id。
- 课件页面是否需要真正的自由拖拽排版，还是先做结构化字段 + 固定布局？建议 MVP 先做固定布局。
- 图表生成是独立结果页，还是作为 PPT 页面中的一种布局？建议定位为页面内组件：AI 先给出图表建议，可直接插入当前页；必要时允许“仅查看图表建议”的辅助面板，但不生成独立课件产物。
- 公式/证明是否需要专门的数学编辑器？建议原型先留公式风险提示和可编辑占位，后续再评估。
- 北印长课件（约 20～100 页）是否需要“按章节分段生成”和断点续生成？建议支持分段生成，避免一次生成失败导致整份课件不可用。

## 9. MVP 边界

本轮原型优先验证：`章节选择 → 带入备课/大纲/资料 → 生成页面骨架 → 页面编辑与来源核对 → 预览/导出`。

暂不在首轮原型中展开：真实 PPT 自由画布、复杂动画、多人协作、自动发布、跨课程资料引用、自动替教师确认公式和证明。
