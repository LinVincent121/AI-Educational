# 模块 PRD

本目录存放每个业务模块的一份完整 PRD。

每份模块 PRD 统一包含：页面、字段、枚举、交互、弹窗、数据关系、业务流程图、系统流程图、权限、状态、AI/Prompt、埋点、异常和验收标准。

文件命名规则：`编号-模块英文名.md`。

当前文件：

- `01-course-workspace.md`：我的课程 / 课程总览。
- `02-material-library.md`：课程资料库。
- `03-syllabus.md`：教学大纲。
- `04-teaching-calendar.md`：教学日历。
- `04-teaching-calendar-isolation.md`：教学日历页面隔离规范（作用域、公共区域保护、CSS/JS/Loader 边界和回归验收）。
- `05-chapter-preparation.md`：备课工作台（章节备课）。
- `06-courseware.md`：课件制作。
- `07-assignment.md`：作业管理。
- `08-exam.md`：试卷管理（试卷与题库）。
- `09-notifications.md`：消息提醒（全局模块）。
- `10-system-settings.md`：系统设置（含模型信息管理）。
- `11-grade-analysis.md`：学生画像（成绩导入、计算、学情分析与报告）。
- `12-version-review.md`：版本与审核统一中心（版本、差异、提交、审核、启用与归档）。
- `13-home.md`：首页与全局总览（课程摘要、待办、消息和快捷入口）。
