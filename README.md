# AI-Educational · 高校课程教学 AI 工作台（AI 教务系统）

> 以课程为核心工作空间、以课程资料库/知识库为基础、以 AI 对话和结构化教学工具为工作方式的**教师教学工作台**原型项目。当前阶段交付物为「需求文档 + 纯静态可交互原型」。

## 项目定位

面向高校教师的备课与教学管理场景，围绕一条主线展开：

```text
创建课程(上传主教材)
  → 资料处理/解析确认
  → 教学大纲(8 大结构区块, 教秘审核)
  → 教学日历(16 周, 教秘核对)
  → 章节备课 → 课件制作 → 作业管理 → 试卷管理
  → 成绩导入 → 学生画像(学情分析)
```

核心设计原则：

- 课程是全部数据的隔离边界；一课程版本只有一份当前有效主教材。
- 原始资料、正式内容不可直接覆盖，修改产生新版本/修订记录。
- **AI 输出默认是可编辑草稿**，必须标记来源、生成时间与人工确认状态；AI 不做审核决策。
- 只有**教学大纲、教学日历、正式试卷**需要教学秘书审核（退回必填原因、3 个工作日 SLA、不能自审）；备课/课件/作业教师确认即生效。
- 课程归档后全局只读，仅可查看、对比、导出。

## prototype/（原型侧）说明

- **纯静态、离线可用**：双击 `prototype/index.html` 即可浏览，不需要后端/数据库/构建步骤。
- **架构**：hash 路由 + 单一 `#app` 容器；每个 hash 由全局函数渲染整页；`js/core/course-v2-loader.js` 是唯一模块注册表（加载顺序即覆盖优先级）；交互函数挂 `window.*`，模块间靠链式覆盖协作。
- **版本号**：所有脚本带 `?v=YYYYMMDD-NN` 缓存版本（loader 与 index.html 同步维护）。改动 JS 后必须递增版本号，否则浏览器会命中旧缓存。
- **校验**：在 `prototype/` 下运行 `node tools/dev-check.mjs`，检查入口、模块引用、JS 语法与重复全局覆盖告警。
- 当前原型完成度与演示路径详见 [`prototype/README.md`](prototype/README.md)。
