EduWork 首页：三个设计方向

教育版 WorkBuddy。首页承载「对话 / 任务 / 教学」三大模式；教学模块沿用现有工作台界面，首页只做新入口——AI 在对话中生成初稿，成稿一键进入对应教学页面编辑。

模式规划

三种模式共用一个输入框与侧栏历史，切换的是"AI 的工作方式"。

💬 对话

即问即答：概念讲解、内容改写、随堂出题、教学文案，答案留在对话里。

✅ 任务

异步执行：批改作业、整理文献、汇总学情等多步骤工作后台完成，进度在首页与侧栏可查。

🎓 教学

教育工作流入口：一句话生成初稿，成稿落到教学大纲、日历、备课、课件等现有工作台精修。

教学入口 → 落地页面（界面不变，仅入口变化）

首页生成的内容最终都进入现有原型页面完成编辑与浏览。

首页入口生成方式落地页面（现有界面）
教学大纲对话生成 16 周大纲初稿教学大纲工作台 #course/syllabus
教学日历按学期周历智能排课教学日历 #course/calendar
备课工作台生成教案初稿 + 匹配资料备课工作台 #course/preparation

作业知识库历史题目结构化入库作业知识库 #course/assignment
试卷组卷按知识点 / 难度智能组卷试卷管理 #course/exam

三个风格方向

均保留 WorkBuddy 的结构骨架（左侧栏 + 居中问候 + 模式切换 + 大输入框 + 快捷卡片），可在页内真实切换三种模式。

方向 A青樟 · 与现有系统同语言

延续原型薄荷绿 + 衬线标题的学术气质，首页与教学工作台浑然一体，改造成本最低。
方向 B · ✓ 当前选定EduWork · WorkBuddy 同源 × 薄荷绿

结构复刻 WorkBuddy，配色切换为现有系统薄荷绿；已按反馈迭代：侧栏区块导航（新建任务 / 专家·技能 / 资料库 / 消息提醒）、去除模式说明文案。
方向 C今日课表 · 教育原生

纸面 + 板书绿 + 楷体问候，把"从哪开始"排成一张当日课程表，最具校园记忆点、差异最大。

概念稿说明：三页均为纯静态 HTML（无外部依赖，双击即开），模式切换 / 快捷标签 / 点击反馈已做成真实交互；落地跳转在概念稿中以提示说明，正式版将接入 prototype/index.html 的 hash 路由。演示数据沿用原型中的林老师与《经济学原理》课程。
